Endpoints

OpenAI-compatible TTS with zero-shot voice cloning. LAN needs no auth; WAN goes through Authentik.
Swagger UI ↗ ReDoc ↗ API info page ↗ /health ↗ Qwen3-TTS docs ↗
MethodPathPurpose
POST/v1/audio/speechGenerate speech — main endpoint
POST/v1/audio/voice-cloneStateless clone (audio in, speech out)
POST/v1/transcribeWhisper transcription of ref audio → text
POST/v1/style-suggestLLM (Lemonade) → style instruction from a vibe
GET/v1/voicesPreset voices + clone:<name> profiles
GET/v1/modelsAvailable model keys
GET·POST·PUT·DELETE/v1/voice-profilesVoice profile CRUD (+ /{id}/ref-audio)
GET·POST·PUT·DELETE/v1/clipsSaved clip library (+ /{id}/audio, /stream.mp3, /play)
GET/v1/speakersSonos/media players via Home Assistant
GET/healthBackend / model / device status

Preset vs Clone: preset voices (Vivian, Serena…) are pre-trained speakers built into the CustomVoice models — pick a name, no audio needed. Clone voices (clone:<name>) are zero-shot clones from your reference audio via the Base models — different checkpoints, auto-selected by voice. Models swap on demand; first request per model pays ~5–30s load.

      
Models auto-swap on demand — first request per model pays load time (~5–30s). Saved clone: profiles cache the voice prompt → faster than raw ref_audio. Typical generation 10–30s (~3× realtime on 0.6B-Base). stream:true returns raw PCM chunks — concatenate and wrap in a WAV header client-side.
